G1.0.0-RC1.12
🌏
여행·일상용 한국어 ↔ 라오어 통역앱

RC1.10 설명서는 현재 RC1.9 기능을 기준으로 다시 정리했습니다. 앱 본문 기능과 배치는 이번 버전에서 변경하지 않았습니다.

1. 가장 빠른 사용법

수동: 말하거나 입력 → 번역하기 · ແປ → 결과 확인 → 듣기/복사/크게보기.
자동통역: 자동통역을 켜고 말하면 STT 완료 후 필요한 최소 교정을 거쳐 자동 번역되고 결과가 TTS로 재생됩니다. 키보드 입력은 자동번역하지 않습니다.

2. 하단 고정바

자동통역 · ແປອັດຕະໂນມັດ — 음성입력 결과만 자동 번역/TTS.
언어전환 · ສະຫຼັບພາສາ — 한국어→라오어 / 라오어→한국어 전환.
한국어/라오어 말하기 — 현재 입력언어에 맞춰 음성입력을 시작/종료/취소.
번역하기 · ແປ — 기존 번역 버튼과 같은 기능.

3. 음성입력과 자동교정

STT 결과의 언어 스크립트를 검사하고 필요하면 기존 복구 경로를 사용합니다. 깨끗한 문장은 그대로 두고, 의심되는 말더듬·반복·명백한 문맥 오인식만 보수적으로 최소 교정합니다. 숫자·시간·가격·이름·장소·브랜드·부정/허용 같은 중요한 정보는 함부로 바꾸지 않도록 보호합니다.

4. 의미확인과 결과 기능

의미확인은 정번역과 별도의 역번역 호출로 동작합니다. 결과 아래에서 듣기 / 복사 / 크게보기를 사용할 수 있습니다. 크게보기는 맞은편 사람이 읽기 쉽도록 번역문을 180° 회전해 표시하고 닫기 버튼은 사용자 방향을 유지합니다.

5. 최근대화와 부부대화 앱

최근대화는 이 기기에 저장되고 접기/펼치기가 가능합니다. 부부대화 버튼은 역할이 고정된 부부 전용 번역 앱으로 이동합니다.

ແອັບລ່າມ ເກົາຫຼີ ↔ ລາວ ສຳລັບການເດີນທາງ ແລະ ຊີວິດປະຈຳວັນ

ຄູ່ມື RC1.10 ຖືກປັບໃໝ່ຕາມຟັງຊັນທີ່ໃຊ້ຈິງໃນ RC1.9. ຮອບນີ້ບໍ່ໄດ້ປ່ຽນໜ້າແອັບຫຼັກ.

1. ວິທີໃຊ້ທີ່ໄວທີ່ສຸດ

ແບບປົກກະຕິ: ເວົ້າ ຫຼື ພິມ → ກົດ 번역하기 · ແປ → ເບິ່ງຜົນ → ຟັງ/ຄັດລອກ/ເບິ່ງຕົວໃຫຍ່.
ແປອັດຕະໂນມັດ: ເປີດ 자동통역 ແລ້ວເວົ້າ. ຫຼັງ STT ສຳເລັດ ແອັບຈະກວດ/ແກ້ໄຂແບບຈຳກັດ, ແປ ແລະ ອ່ານຜົນແປດ້ວຍສຽງ. ຂໍ້ຄວາມທີ່ພິມເອງຈະບໍ່ແປອັດຕະໂນມັດ.

2. ແຖບປຸ່ມດ້ານລຸ່ມ

자동통역 · ແປອັດຕະໂນມັດ — ແປ ແລະ TTS ອັດຕະໂນມັດສຳລັບຂໍ້ຄວາມທີ່ມາຈາກສຽງ.
언어전환 · ສະຫຼັບພາສາ — ສະຫຼັບ ເກົາຫຼີ→ລາວ / ລາວ→ເກົາຫຼີ.
말하기 · ເວົ້າ — ເລີ່ມ/ຢຸດ/ຍົກເລີກການຮັບສຽງຕາມພາສາປັດຈຸບັນ.
번역하기 · ແປ — ເຮັດວຽກເໝືອນປຸ່ມແປຫຼັກ.

3. ການຮັບສຽງ ແລະ ການແກ້ຂໍ້ຄວາມ

ແອັບກວດວ່າຜົນ STT ເປັນພາສາທີ່ຖືກຕ້ອງ ແລະ ໃຊ້ເສັ້ນທາງກູ້ຄືນເມື່ອຈຳເປັນ. ປະໂຫຍກທີ່ດີຢູ່ແລ້ວຈະບໍ່ຖືກປ່ຽນ. ຈະແກ້ພຽງການຕິດຄຳ, ການຊ້ຳ ຫຼື ຄຳຜິດທີ່ຊັດເຈນແບບຈຳກັດ. ຕົວເລກ, ເວລາ, ລາຄາ, ຊື່, ສະຖານທີ່, ແບຣນ ແລະ ຄວາມໝາຍປະຕິເສດ/ອະນຸຍາດຈະຖືກຮັກສາ.

4. ກວດຄວາມໝາຍ ແລະ ຜົນແປ

ກວດຄວາມໝາຍ ໃຊ້ການແປກັບແບບແຍກຕ່າງຫາກ. ສາມາດ ຟັງ / ຄັດລອກ / ເບິ່ງຕົວໃຫຍ່. ໂໝດຕົວໃຫຍ່ຈະໝຸນຂໍ້ຄວາມ 180° ໃຫ້ຄົນທີ່ນັ່ງຝັ່ງກົງຂ້າມອ່ານໄດ້ງ່າຍ.

5. ປະຫວັດ ແລະ ແອັບຄູ່ສົມລົດ

ປະຫວັດການສົນທະນາຖືກເກັບໄວ້ໃນອຸປະກອນນີ້ ແລະ ສາມາດພັບ/ເປີດໄດ້. ປຸ່ມ 부부대화 ຈະໄປຫາແອັບທີ່ກຳນົດບົດບາດສາມີ/ພັນລະຍາ.
