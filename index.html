G1.0.0-RC1.7
🌏
여행과 일상에서 바로 쓰는 한국어 ↔ 라오어 통역앱

음성 또는 글로 말하고, 번역 결과와 자동 의미확인을 확인한 뒤 상대방에게 들려주거나 크게 보여줄 수 있습니다.

1 기본 사용
⇄언어 선택한국어 ↔ 라오어
→
🎙️말하기/입력음성 또는 직접 입력
→
➤번역하기버튼 한 번
→
✅결과 확인의미확인 자동 실행
2 음성입력
🎙️ 음성입력을 누르고 말한 뒤 같은 버튼을 다시 누르면 종료됩니다. 인식 처리 중에 다시 누르면 취소할 수 있습니다.
새 음성입력이 실제로 시작되면 이전 입력문은 자동으로 비워져 새 문장을 바로 말할 수 있습니다. STT 완료 뒤에는 키보드가 자동으로 올라오지 않습니다.
3 의미확인 · 자동 역번역
번역이 끝나면 결과 문장을 다시 원래 언어로 번역해 의미가 제대로 전달됐는지 확인합니다. 오른쪽에는 소요시간만 간단히 표시됩니다.
의미확인 중 버튼을 누르면 중지할 수 있고, 다시 누르면 재실행할 수 있습니다.
4 결과 사용
🔊 듣기상대 언어 음성으로 재생
📋 복사번역본 + 의미확인 2줄 복사
📱 크게 보기문장을 180° 돌려 상대방에게 바로 보여주기
🔄 재번역같은 원문을 다시 번역
5 최근 대화
이 기기에 최근 대화를 최대 50개 저장합니다. 최근 대화 제목을 누르면 목록을 펼치거나 접을 수 있습니다. 불러오기는 원문만 입력칸에 다시 넣습니다.
6 부부대화와 연결 설정
💬 부부대화부부 전용 번역앱으로 이동
⚙️ 설정연결 상태·경로·진단 확인
💡 사용 팁
사람 이름, 장소, 숫자, 시간처럼 중요한 내용은 번역 결과와 의미확인을 함께 확인하면 더 안전합니다. 통역이 급할 때는 짧고 한 문장씩 말하는 것이 가장 안정적입니다.
