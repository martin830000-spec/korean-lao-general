한국어 ↔ 라오어 일반 통역앱

여행과 일상에서 상대방과 자연스럽게 대화하기 위한 한국어 ↔ 라오어 일반 통역앱입니다. 텍스트나 음성으로 입력하고 번역문·의미확인·원문을 한 화면에서 확인할 수 있습니다.

1. 처음 사용할 때 — 30초 빠른 시작

① 언어 확인 — 화면 위쪽에서 지금 말할 언어와 상대방에게 보여줄 언어를 확인합니다.
② 말하거나 입력 — 한국어/라오어 말하기를 누르거나 입력창에 직접 문장을 적습니다.
③ 번역하기 — 파란색 번역하기 버튼을 누릅니다.
④ 결과 활용 — 번역이 끝나면 결과 카드에서 번역문 → 의미확인(역번역) → 원문 순서로 확인합니다. 하단 원문의 수정을 누르면 다시 입력창에서 고칠 수 있습니다.
가장 쉬운 사용법: 짧고 분명한 한 문장씩 말하면 음성인식과 번역이 더 안정적입니다.

2. 한국어 ↔ 라오어 방향 바꾸기

현재 번역 방향은 메인 타이틀에 한국어 → 라오어 또는 라오어 → 한국어로 표시됩니다. 방향을 바꾸려면 하단 고정바의 언어전환을 누릅니다. 방향을 바꾸면 화면 전체 버튼·안내문·상태문구도 현재 입력 언어 기준으로 함께 바뀝니다.
  • 한국어로 말할 때: 🇰🇷 한국어 → 🇱🇦 라오어
  • 라오어로 말할 때: 🇱🇦 라오어 → 🇰🇷 한국어
  • 사람의 성별·나이·관계는 원문에 없는 내용을 임의로 만들어 넣지 않습니다.

3. 음성입력 — 버튼 상태를 보고 사용하세요

말하기를 누르면 마이크가 준비되고, 녹음 중에는 듣고 있다는 상태가 표시됩니다. 다시 누르면 녹음을 끝내거나 처리 중인 음성인식을 취소할 수 있습니다.
마이크 준비
권한과 음성 연결을 준비하는 단계입니다.
듣는 중
말하고 있는 내용을 받고 있습니다.
인식 중
음성을 글자로 바꾸고 있습니다.
완료
인식된 문장이 입력창에 들어갑니다.
소음이 많은 곳: 휴대폰을 조금 가까이 두고 한 문장씩 또박또박 말하세요. 이름·주소·가격·시간은 인식된 글자를 한 번 눈으로 확인한 뒤 번역하는 것이 좋습니다.

4. 자동통역 — 말을 끝내면 자동 번역

자동통역 ON 상태에서 음성입력을 사용하면, 음성인식이 정상적으로 끝난 뒤 자동으로 번역합니다. 음성출력이 켜져 있을 때만 상대 언어 음성을 자동 재생합니다. 키보드로 직접 입력한 문장은 자동으로 번역하지 않습니다.
  • 대화를 빠르게 주고받을 때 유용합니다.
  • 음성인식이 실패하거나 사용자가 취소하면 자동번역도 시작하지 않습니다.
  • 자동통역이 불편한 상황에서는 OFF로 두고 번역 버튼을 직접 누르면 됩니다.

5. 의미확인 — 번역 뜻이 크게 어긋나지 않았는지 보기

번역 후 의미확인은 번역문을 다시 원래 언어 쪽으로 확인해, 전달하려던 핵심 뜻이 유지되는지 살펴보는 보조 기능입니다.
중요: 의미확인은 ‘100% 정답 판정’이 아닙니다. 계약, 의료, 법률, 큰 금액, 정확한 주소·시간처럼 실수가 큰 영향을 줄 수 있는 내용은 숫자와 고유명사를 직접 다시 확인하세요.

6. 결과 화면의 주요 기능

🔊 상단 음성 버튼
상단바 바로 아래의 자동 음성출력 / 듣기 두 버튼을 항상 같은 위치에서 사용합니다. 듣기는 번역 결과가 있을 때 재생합니다.
📋 복사
번역본과 의미확인(역번역)이 준비되면 두 줄을 함께 복사해 메신저나 문자에 붙여넣습니다.
⛶ 크게보기
번역 결과카드 우측 상단에서 ↺ 전체 지우기 오른쪽의 크게보기를 누르면 번역문만 크게 표시합니다. 처음 열 때는 항상 정방향이며, ↻ 회전을 누를 때만 180° 회전합니다. 닫았다가 다시 열면 다시 정방향입니다.
↻ 재번역
현재 원문을 다시 번역합니다.
🗑 지우기
입력 카드 우상단의 입력 지우기는 입력문만 지우고, 결과 카드 우상단의 ↺ 전체 지우기는 현재 원문·번역·의미확인을 비웁니다. 최근 대화 기록은 그대로 둡니다.
대면 대화 팁: 소리가 잘 안 들리는 곳에서는 크게보기로 글자를 보여주는 것이 빠르고 확실할 수 있습니다.

7. 최근 대화 다시 사용하기

최근 대화는 이 기기에 최대 50개까지 보관됩니다. 자주 쓰는 문장을 다시 불러오면 같은 내용을 반복 입력할 필요가 없습니다. 불러오기를 눌러도 키보드를 강제로 열지 않으며, 불러온 문장을 수정하지 않고 다시 번역해도 같은 항목을 새로 쌓지 않습니다. 문장을 수정한 뒤 번역하면 새로운 기록으로 저장할 수 있습니다. 공용 기기에서는 사용 후 기록을 지우는 것이 좋습니다.

8. 하단 고정 영역 — 앱 전환 + 빠른 기능

윗줄의 💑 부부대화 | 🌏 일반 통역은 앱 전환바입니다. 일반 통역 화면에서는 일반 통역이 선택 상태라 다시 눌러도 이동하지 않고, 부부대화를 누르면 본앱으로 돌아갑니다. 그 아래에는 자동통역 · 언어전환 · 말하기 · 번역하기가 고정되어 있어 긴 화면에서도 바로 사용할 수 있습니다. 크게보기는 번역 결과카드 우측 상단에서 사용합니다.

9. 잘 안 될 때 확인할 것

  • 마이크가 안 됨: 브라우저/앱의 마이크 권한이 허용되어 있는지 확인합니다.
  • 음성인식이 자주 틀림: 주변 소음을 줄이고 짧은 문장으로 다시 말합니다.
  • 번역이 늦음: 버튼을 여러 번 연속으로 누르지 말고 현재 ‘번역 중/인식 중’ 상태가 끝나는지 기다립니다.
  • 음성이 안 들림: 휴대폰 미디어 볼륨과 무음 설정을 확인한 뒤 듣기를 다시 누릅니다.
  • 이상한 번역: 원문을 더 짧고 구체적으로 고쳐 다시 번역하고 의미확인 결과도 함께 봅니다.

10. 꼭 기억하면 좋은 사용 팁

추천: “기사님, 이 주소로 가 주세요.”처럼 주어와 목적을 분명하게 말하면 좋습니다.
확인 권장: 사람 이름, 호텔·병원·가게 이름, 전화번호, 금액, 날짜, 시간, 주소, 약 이름은 번역 전에 인식된 원문과 번역 결과를 한 번 더 확인하세요.
서로 이해가 안 될 때: 같은 긴 문장을 반복하지 말고 두세 개의 짧은 문장으로 나누면 의미 전달이 더 쉬워집니다.

ເມື່ອເປີດ ແປອັດຕະໂນມັດ ແລ້ວໃຊ້ສຽງ, ຫຼັງຈາກຮັບສຽງສຳເລັດ ແອັບຈະແປອັດຕະໂນມັດ. ຈະອ່ານຜົນແປດ້ວຍສຽງສະເພາະເມື່ອເປີດ ການສົ່ງສຽງ. ຖ້າປິດສຽງ ຈະແປແຕ່ບໍ່ອ່ານອັດຕະໂນມັດ. ຂໍ້ຄວາມທີ່ພິມເອງຈະບໍ່ແປອັດຕະໂນມັດ.

5. ກວດຄວາມໝາຍ

ຟັງຊັນນີ້ແປຜົນແປກັບເພື່ອຊ່ວຍເບິ່ງວ່າໃຈຄວາມຫຼັກຍັງຢູ່ຄົບຫຼືບໍ່.
ສຳຄັນ: ນີ້ບໍ່ແມ່ນການຢືນຢັນວ່າຖືກ 100%. ຂໍ້ຄວາມກ່ຽວກັບສັນຍາ, ການແພດ, ກົດໝາຍ, ເງິນຈຳນວນຫຼາຍ, ທີ່ຢູ່ ແລະ ເວລາຄວນກວດອີກຄັ້ງ.

6. ຟັງຊັນຫຼັກຂອງໜ້າຜົນແປ

🔊 ປຸ່ມສຽງດ້ານເທິງ
ປຸ່ມ ສຽງອັດຕະໂນມັດ / ຟັງ ຢູ່ໃຕ້ແຖບຫົວຂໍ້ ແລະຢູ່ຕຳແໜ່ງດຽວສະເໝີ.
📋 ຄັດລອກ
ເມື່ອຜົນແປ ແລະ ການກວດຄວາມໝາຍ (ແປກັບ) ພ້ອມແລ້ວ ຈະຄັດລອກ 2 ແຖວໄປ Messenger ຫຼື ແອັບອື່ນ.
⛶ ເບິ່ງຕົວໃຫຍ່
ໃນກາດຜົນແປ ປຸ່ມ ເບິ່ງຕົວໃຫຍ່ ຢູ່ຂວາຂອງ ↺ ລ້າງທັງໝົດ. ກົດແລ້ວຈະສະແດງສະເພາະຜົນແປໃຫ້ໃຫຍ່. ທຸກຄັ້ງທີ່ເປີດຈະເປັນທິດປົກກະຕິ; ກົດ ↻ ໝຸນ ເທົ່ານັ້ນຈຶ່ງໝຸນ 180°. ປິດແລ້ວເປີດໃໝ່ຈະກັບເປັນທິດປົກກະຕິ.
↻ ແປໃໝ່
ແປຕົ້ນສະບັບເດີມອີກຄັ້ງ.
🗑 ລ້າງ
ລ້າງຕົ້ນສະບັບ, ຜົນແປ ແລະ ການກວດຄວາມໝາຍຂອງການສົນທະນາປັດຈຸບັນ ໂດຍບໍ່ລຶບປະຫວັດຫຼ້າສຸດ.

7. ການສົນທະນາຫຼ້າສຸດ

ເກັບໄດ້ສູງສຸດ 50 ລາຍການໃນອຸປະກອນນີ້. ການກົດຮຽກກັບຄືນຈະບໍ່ບັງຄັບເປີດແປ້ນພິມ. ຖ້າຮຽກຂໍ້ຄວາມເກົ່າກັບຄືນແລ້ວແປຊ້ຳໂດຍບໍ່ແກ້ໄຂ ຈະບໍ່ເພີ່ມລາຍການຊ້ຳ. ຖ້າແກ້ໄຂຂໍ້ຄວາມແລ້ວແປ ສາມາດບັນທຶກເປັນລາຍການໃໝ່ໄດ້.

8. ພື້ນທີ່ຄົງທີ່ດ້ານລຸ່ມ — ສະຫຼັບແອັບ + ປຸ່ມດ່ວນ

ແຖວເທິງ 💑 ສົນທະນາຄູ່ສົມລົດ | 🌏 ລ່າມທົ່ວໄປ ແມ່ນແຖບສະຫຼັບແອັບ. ໃນໜ້ານີ້ ລ່າມທົ່ວໄປ ຈະຖືກເລືອກໄວ້; ກົດ ສົນທະນາຄູ່ສົມລົດ ເພື່ອກັບໄປແອັບຫຼັກ. ແຖວລຸ່ມມີ ແປອັດຕະໂນມັດ · ສະຫຼັບພາສາ · ເວົ້າ · ແປ ຢູ່ຕະຫຼອດ. ປຸ່ມເບິ່ງຕົວໃຫຍ່ຢູ່ມຸມຂວາເທິງຂອງກາດຜົນແປ.

9. ຖ້າໃຊ້ບໍ່ໄດ້

  • ໄມໂຄຣໂຟນບໍ່ເຮັດວຽກ: ກວດສິດໄມໂຄຣໂຟນ.
  • ຮັບສຽງຜິດຫຼາຍ: ຫຼຸດສຽງລົບກວນ ແລະ ເວົ້າສັ້ນລົງ.
  • ແປຊ້າ: ຢ່າກົດປຸ່ມຊ້ຳຫຼາຍເທື່ອ; ລໍຖ້າສະຖານະປັດຈຸບັນສຳເລັດ.
  • ບໍ່ມີສຽງ: ກວດລະດັບສຽງມີເດຍຂອງໂທລະສັບ.

10. ຄຳແນະນຳທີ່ຄວນຈື່

ແນະນຳ: ເວົ້າໃຫ້ຊັດເຈນວ່າໃຜ, ຈະເຮັດຫຍັງ, ຢູ່ໃສ.
ຄວນກວດ: ຊື່ຄົນ, ຊື່ໂຮງແຮມ/ໂຮງໝໍ, ເບີໂທ, ລາຄາ, ວັນທີ, ເວລາ, ທີ່ຢູ່ ແລະ ຊື່ຢາ.
ຖ້າຍັງບໍ່ເຂົ້າໃຈ: ແບ່ງປະໂຫຍກຍາວເປັນ 2–3 ປະໂຫຍກສັ້ນ.
